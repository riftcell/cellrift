The endpoint 447700900202 is told `auth=auth-sha265`. All three auth objects still load and
`pjsip show auths` lists them, so only the per-endpoint check can catch this.

```sh

PJSIP_CONF=test/interop/asterisk/pjsip-probe-typo.conf bash test/interop/up-sip.sh; echo "exit=$?"
```

## G1 run-sip-scenario.sh gate_peer_challenged, fired by a rig that never challenges

The rig is booted with every `auth=` line removed (EXPECT_ENDPOINTS=0, because the boot gate
would otherwise refuse first). The scenario run is a copy of register_digest_auth.yaml with
its `response.auth.*` assertions removed and its comment line about them dropped, so that
Cellrift's own account of the run is green and only the peer's log can say no challenge was sent.

```sh
grep -v '^auth=' test/interop/asterisk/pjsip.conf > test/interop/asterisk/pjsip-probe-noauth.conf
PJSIP_CONF=test/interop/asterisk/pjsip-probe-noauth.conf EXPECT_ENDPOINTS=0 bash test/interop/up-sip.sh; echo "exit=$?"
grep -v 'response\.auth\.' scenarios/ims/register_digest_auth.yaml > $SCRATCH/stripped.yaml
AUTH_SCENARIO=$SCRATCH/stripped.yaml OUT=$SCRATCH/p2out bash test/interop/run-sip-scenario.sh; echo "exit=$?"
```
